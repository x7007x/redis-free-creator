# Redis Free Account Creator

Creates a brand new Redis Cloud account for you with a free database ready to use. You do not need to sign up for anything yourself and you do not need to fill in any forms

## What happens when you run it

- A temporary email inbox is created to receive the activation message
- A new Redis Cloud account is created and activated through that email
- A free database with 30 MB of storage is created for you
- The database is tested live to make sure it is working and answering
- You receive the account details and the full connection link ready to copy and use right away

## What you get

- The account email and password
- The full connection link for the database which is called the Storage URL
- Everything appears at the top of the run page and also in a file attached to every run

## How to run it

- Open the Actions page of this repository
- Choose Create Redis Free Account
- Press Run workflow
- Wait about two and a half minutes and your details will be ready at the top of the run page

## Good to know

- The free database holds 30 MB and is great for testing and small projects
- Every run creates a separate new account with fresh details
- Runs are manual only and there is no automatic daily run
